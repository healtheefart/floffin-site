floffin 개인정보처리방침

시행일: 2026.11.24

floffin(이하 "서비스")은 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 지킵니다.

1. 처리하는 개인정보

  • 로그인 정보: Apple·Google·카카오 로그인 시 제공되는 계정 식별자와 이메일 주소
  • 메일 계정 연결 정보: 연결한 메일 주소, 메일 서비스 접근 토큰 또는 앱 비밀번호
  • 기기 정보: 푸시 알림 토큰, 알림 암호화용 기기 공개키
  • 설정 정보: 이용자가 만든 메일 정리 규칙, 알림 설정

2. 처리 목적

  • 여러 메일 계정의 메일 조회·정리·발송 기능 제공
  • 새 메일 도착 알림과 이용자가 정한 메일 정리 규칙 실행
  • 회원 식별과 부정 이용 방지

3. 메일 내용의 처리

  • 메일 본문·제목·발신자는 서버에 저장하지 않습니다. 새 메일 알림과 규칙 판단에 필요한 범위에서 메모리에서만 처리하고 즉시 폐기합니다.
  • 알림에 표시되는 발신자·제목·미리보기는 이용자 기기의 공개키로 암호화해 전송하며, 기기에서만 복호화됩니다.
  • 메일 목록과 본문은 이용자 기기에서 각 메일 서비스와 직접 통신해 가져옵니다.

4. 보관 기간과 파기

  • 메일 계정 연결 정보는 안전한 암호 알고리즘으로 암호화해 저장하며, 계정 연결을 해제하면 즉시 파기하고 발급받은 토큰을 철회(revoke)합니다.
  • 회원 탈퇴 시 메일 계정 연결 정보, 규칙, 기기 정보를 지체 없이 파기합니다.

5. 제3자 제공과 처리 위탁

서비스는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 서비스 운영을 위해 다음 업체의 인프라를 이용합니다: 서버 호스팅·암호화 키 관리 서울 리전 클라우드 서버 업체(확정 후 고지), 푸시 알림 전송 Google Firebase Cloud Messaging.

6. Google 사용자 데이터

floffin이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. Gmail 데이터는 이용자에게 메일 기능을 제공하는 목적으로만 사용하며, 광고에 사용하거나 사람이 열람하지 않습니다(이용자 동의, 보안 목적, 법령상 의무가 있는 경우 제외).

7. 이용자의 권리

이용자는 언제든지 앱에서 메일 계정 연결을 해제하거나 탈퇴할 수 있으며, 개인정보 열람·정정·삭제를 요청할 수 있습니다.
